# bunchoniki Retro

iPhone でレトロゲーム（GB/GBC/GBA/NES/SNES/N64/NDS/Genesis）を**合法的に**楽しむ方法を日本語で提供する情報サイトです。

🌐 **https://retrogame.bunchoniki.com**

## 差別化ポイント

- **Delta + GB Operator + 著作権法第30条** の統合解説（日本語圏で他に存在しない）
- **エミュレータ法律早見表** — GB系（合法）vs Switch系（違法リスク）の技術的・法的整理
- **homebrew 無料ゲーム特集** — itch.io 配布の合法 ROM 紹介

## 姉妹サイト

サイドローディング・AltStore PAL・スマホ新法解説：[bunchoniki Store](https://altstore-jp.bunchoniki.com)（[sazanamiNiki/altStore](https://github.com/sazanamiNiki/altStore)）

## 開発

```bash
npm install
npm run dev      # localhost:4321
npm run build    # dist/ に出力
npm run preview  # ビルド結果プレビュー
```

## デプロイ

`master` への push で GitHub Actions が GitHub Pages に自動デプロイします。
