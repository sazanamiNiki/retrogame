gavel 合法性の根拠

なぜ「自分のカートリッジから吸い出して遊ぶ」のは合法？

verified 著作権法 第30条「私的使用のための複製」

日本の著作権法は「個人的にまたは家庭内その他これに準ずる限られた範囲内において使用することを目的とするときは、その使用する者が複製することができる」と定めています。自分が所有するカートリッジから ROM を吸い出して、自分の iPhone で遊ぶ行為は、まさにこの「私的使用のための複製」に該当します。

info GB / SFC / N64 等のレトロ機種はコピーガード（TPM）が無い

「コピーガードを外して複製する」行為は私的複製の例外として違法ですが、ゲームボーイやスーパーファミコン等のレトロ機種にはそもそもコピーガードが施されていません。技術的にも法的にも、複製は合法です。一方、Nintendo Switch のように AES-128 で暗号化されたゲームを解除する行為は不正競争防止法に抵触します。

エミュレータ法律早見表

機種別に「合法的に遊べるか」をまとめました。詳しい解説はエミュレータと著作権を参照。

機種 TPM 合法性 補足
GB / GBC / GBA 無し ⭕ 合法 GB Operator で自家吸い出し可能
NES / SNES 無し ⭕ 合法 SN Operator 等で吸い出し可能

よくある質問

Q. iPhoneでレトロゲームを遊ぶのは合法ですか？

Deltaエミュレータ自体はApp Storeで配信されている合法アプリです。ROMの利用も、自分が所有するカートリッジから「GB Operator」などで吸い出した場合は著作権法第30条の私的複製として認められています。一方、ネット上から無断でROMをダウンロードする行為は著作権侵害となります。

ポイント： 正規品のカートリッジを買って自分で吸い出すのが、唯一の合法ルートです。

Q. Nintendo Switchのゲームも遊べますか？

事実上不可能、かつ高い法的リスクがあります。Switchはゲームに暗号化（AES-128）が施されており、その解除は不正競争防止法上の「技術的制限手段の回避」に該当する可能性が高いためです。2026年2月には任天堂がGitHub上のSwitch系エミュレータ13件以上にDMCA通知を一斉送付し、主要なエミュレータはほぼ全て開発停止に追い込まれました。

ポイント： 現行機のエミュレータには手を出さないのが安全です。レトロ機（GB/SFC/N64等）はTPMが無いため合法的に遊べます。

Q. PCを持っていなくてもカートリッジから吸い出せますか？

残念ながらGB Operator など主要なリーダーは Windows / Mac / Linux 専用で、iPhone 単体ではカートリッジ吸い出しはできません。ただし、吸い出したROMをiPhoneの「ファイル」アプリに転送すれば、Deltaで遊べます。または、無料のhomebrewゲーム（itch.ioで配布）ならPC不要で今すぐ遊び始められます。

ポイント： まずはhomebrewから始めて、ハマったらGB Operatorで自分のソフトを楽しむのが王道です。

Q. AltStore PALって必要ですか？

基本的な Delta だけならApp Store版で十分で、AltStore PAL は必須ではありません。ただし、AltStore PAL 経由の Delta は JIT 有効化により Fast Forward が約 3 倍速になるメリットがあります。詳細は姉妹サイト bunchoniki Store を参照してください。

ポイント： まずは App Store の Delta から始めて、もっと高速化したくなったら PAL を検討すれば OK です。
